How to use the Sugargoo spreadsheet

  1. Save the source listing and variant. Open the CAFANS product page, find the original seller link, and check whether Sugargoo accepts it. Record the exact color, size and seller price.
  2. Compare measurements. For shoes, check the listing’s size chart and how it defines foot or insole length. For a hoodie or jacket, compare chest width and body length with a garment you already own.
  3. Budget for the parcel. Add the item price, domestic delivery, agent fees, international shipping and any applicable taxes or duties. Compare shipping lines using your destination, packed weight and box dimensions.
  4. Review warehouse photos. When quality-control (QC) photos are available, check the size tag, color, quantity and visible condition before approving shipment. Review the return window while the parcel is still at the warehouse.

Sugargoo spreadsheet FAQs

What is a Sugargoo spreadsheet?

It’s a product shortlist that helps shoppers compare listings and save their preferred variants before checking whether an agent can order them.

What does the CAFANS price cover?

The table shows a reference item price in USD. Use the seller listing and the agent’s checkout to confirm the current item price, delivery charges and fees.

Why does shipping change after packing?

Some shipping lines charge using the greater of actual weight and volumetric weight. A bulky box can increase the billable weight. Check the selected line’s quote and calculation rules.

Can I order every item through Sugargoo?

Check the original listing in Sugargoo and confirm the variant is in stock. Eligibility can depend on the item and destination.
